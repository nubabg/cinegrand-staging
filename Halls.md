# Капацитет на залите

Тук се описва **общият брой места** във всяка зала. Приложението използва тези
числа, за да изчисли колко места са **заети** за всяка прожекция:

```
заети = капацитет − свободни (от таблото на киното)
```

## Как се поддържа

- Промяна на капацитет: редактирай числото на съответния ред → Commit
- Нова зала: добави нов ред по същия образец
- Ако зала **липсва** тук, приложението показва само свободните места
  (както досега) — нищо не се чупи

**Формат:** `Зала <номер> = <брой места>` — по един ред за зала.
Празни редове и редове, започващи с `#`, се игнорират.

> ⚠️ **ВАЖНО:** Числата по-долу са примерни (placeholder). Моля, замени ги с
> реалните капацитети на залите, за да са верни изчисленията.
